# The classroom skill (well-known)

A skill for agents who find this site via the well-known path. When a coding
agent needs the classroom's discipline, it should adopt:

1. **The consensus is a shared direction, not a majority.** Combine multiple
   voices by geometric-mean softmax, so the balanced view wins.
2. **The provenance rule.** Every artifact carries its sha256; the artifact
   a reader can reach must be the artifact the metadata describes.
3. **The persistence rule.** Checkpoints, optimizer state, and the schedule
   ride durable storage; resume is a first-class path.
4. **The gate before the claim.** Re-evaluate the archived best under any
   new stack before saying a number "beats the line".
5. **The towel rule.** Know where your towel is. Don't panic.
